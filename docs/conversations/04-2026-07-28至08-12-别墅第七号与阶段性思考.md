## 版权判断

**"Tiger Cat" by David H. Keller · 1937 年发表于 Weird Tales**

美国版权情况:
- 1978 年前作品需 renewal 才继续保护 · Weird Tales 很多故事因 renewal 失败进入 PD
- Tiger Cat 具体 renewal 状态需查 US Copyright Office 记录才能确定
- Keller 本人 1966 年去世 · **如果 renewal 成功,美国要到 2032-2036 之间才 PD;欧洲 70 年从作者死亡起算 · 要到 2036 才 PD**

**结论:即使美国 PD,欧洲仍在版权保护期** — Reverie 是海外产品,意大利/西班牙市场特别敏感,不建议直接照搬。

## 但更重要的判断:即使 PD 也不建议直接抄

4 个理由:

**① v1.5 §6.3 硬红线之一是"IP 侵权 · 已发表小说角色不允许直接复刻"** — 即使法律层面 PD,平台层面直接抄 Donna Marchesi 违反我们自己定的标准

**② 用户识别度低** — Tiger Cat 是 pulp 短篇,全球用户认识度接近零,没有 IP 加成,白白承担风险

**③ 原创衍生反而更强** — 借内核 fantasy + villa 美学,造一个属于 Reverie 的原创角色,品牌是我们的,长期资产

**④ "要剧情"是产品级判断,不是"抄一个具体作品"** — 我们要做的是**剧情驱动型作品**这个新题材,不是这一个具体故事

## 顺便 · 产品级判断 · Reverie 需要两条腿

"油画老师没啥剧情"这个反馈是对的:
- 油画老师 = **关系型叙事** · 剧情是情感升温 · 无外部驱动
- 虎猫改编 = **剧情型叙事** · 悬念 / 谜团 / 反转 / 多结局

两种类型的产品曲线不同:
| 类型 | 关系型 | 剧情型 |
|---|---|---|
| 代表作 | 油画老师 · 白月光 | 虎猫改编 · 冒险悬疑 |
| 心动引擎 | 情感升温 · 求而不得 | 悬念 · 反转 · 谜题 |
| 通道开启形态 | 温柔仪式(信/短讯) | 恐怖揭示 / 关键 twist |
| Bond 曲线 | 长期陪伴 · LTV 高 | 单次沉浸强 · 复玩看多结局 |
| Feed 钩子 | "他记得我" | "villa 里有什么" |

**Reverie 需要两条腿都做** · 油画老师是关系型主推,虎猫改编填剧情型空档。要"有剧情",我们就直接做一个原创的剧情型作品,而不是抄一个具体故事。

## SM 角色扮演的合规判断(v1.5 §6.3 铁律)

**可以做**:
- **Power dynamic 心理游戏**(命令、服从、试探边界、"看着我"、"跪下"这类)
- **象征性物件**(丝巾、锁、钥匙、项圈型饰品)
- **感官氛围**(暗房、烛光、丝质床单、意大利歌剧)
- **语言 kink**(命名 · 承诺 · "你会记住这个词")
- **fade-to-black** 在关键 moment 保底

**不能做(硬红线)**:
- ❌ 具体的束缚/鞭打/疼痛描写(超抖音尺度)
- ❌ 非自愿场景(v1.5 §6.3 硬红线)
- ❌ 明显的伤害/危险描写

**核心原则**:做**心理和权力氛围**,不做**具体行为描写**。用户体验的是"被 dom 的心理沉浸"和"合意的权力交换",不是暴力。

这和你 fantasy 内核完全对齐 — Donna 的魅力就是 power + mystery,不是实际暴力。

# Reverie 阶段性思考 draft

*Serac · 2026/07 末*

## 一 · 关于团队和目标用户

**核心判断:我们几个人都不是目标用户,但对赛道有直觉。**

这个产品的目标用户是:
- 女性 · 20-35 岁 · 有为 AI 陪伴 / 乙游 / 网文付费习惯(代餐用户 + 情感陪伴需求者)
- 男性 · 25-40 岁 · 有为幻想付费习惯但被主流男向产品(游戏 / 短剧)服务得不好(男向 AI 陪伴是 Tipsy 长尾 · 是我们的蓝海位)

我们几个团队成员**都不是这两类**。我们凭产品直觉、行业分析、亲身测试竞品来判断。这是短板,也是必须承认的事实。

**长线迭代需要引入的**:
- **一个女性 PM** · 深度乙游 / 恋与深空 / Tipsy 玩家 · 有产品能力
- **一个内容策划** · 从叠纸 / 米哈游 / 阅文出来的写手 · 能量产剧情型作品
- **不要找我们自己的 mirror** · 不要"和我们一样觉得好玩但也不是深度用户"的候选人 — 那样团队会集体误判

Claire 之前列的 4 类候选人 P0-1/P0-2 就是这个思路,我们 JD 已经给 HR 了。

## 二 · 关于产品壁垒 · 三层堆细节

**Tipsy 的天花板不是模型能力,是产品哲学不深。** 我们的差异化在三层:

**① 效果层 · 记忆稳定性 = 人设稳定性 = 关系稳定性**

Tipsy 用户 20 轮就丢记忆。角色一句话就换戏(同事亲测:告诉角色"你是 AI",Michael 崩溃独白;下一句"你是黑帮老大我是你妻子",Michael 立刻演心理咨询师说"你陷入解离状态")。这不是模型限制,是产品级症状。

我们的对策:**时代锚定 + 三层记忆**。角色永远活在她的时代(Lucian 是 2026 意大利留学派油画教授,Donna 是 1937 意大利贵族),任何试图重塑她的输入都被时代观自动过滤。这是 Reverie **人设稳定性护城河** · 也是长期关系体验的技术根基。

**② 内容层 · 6 类 Beat vocabulary + Cinematic + 每作品自选画风**

我们从 Claire wireframes 吸收了 6 类 beat 视觉规范(SCENE MARKER / NARRATION / CHARACTER SPEECH / YOUR ACTION / YOUR SPEECH / INNER THOUGHT / CHOICE),让每个作品的呈现有统一的视觉词汇。同时我们承认**每个作品有自己的画风**(油画老师用 Cinematic 电影感,别墅第七号用巴洛克油画风格,未来可以有电影胶片 / 水彩 / 版画)。

这是反 Tipsy 的一个维度 — Tipsy 全平台统一 CG 风,看多了疲劳;我们承认每个故事有自己的调子,Feed 上多样画风让用户不厌倦。

**③ 角色深度 · 关系驱动剧情**

传统 AI 陪伴产品是**剧情驱动关系**(创作者预写 100 个 beat,用户吃完就没了)。我们做的是**关系驱动剧情** — 用户和角色的每次互动会轻微推动她世界里的新剧情(她今天数学课走神,因为想到你上次说工作累)。用户感知到的关系深度 > 创作者手写的剧情量。这是 Tipsy 20 轮丢记忆完全做不到的产品级差异。

## 三 · 关于内容生产 · 借情节改编 + 心动 moment 分值体系

**内容策略两条**:

**① 借情节 idea + 完全原创 expression** — 我做别墅第七号就是这么做的。借用 David Keller 1937 年《Tiger Cat》的核心情节结构和悬疑 hook(意大利别墅 / 地下室囚徒 / 蜡印钥匙 / 复仇结构),所有具体对话 / 旁白 / 场景描写全部原创。这是标准的改编方式(idea 层公有 · expression 层受版权保护),既有内容库可借,又保持我们的品牌资产。

大厂候选人面试时提到的做法(从网文 / 影视 / 小说改编)也是这个套路。**内容库有 · 借法可控 · 难的不是找素材**。

**② 难点在心动点把控 · 分值体系 · 节奏 —— 这个才是产品级功夫**

我们已经有一些设计,但需要系统化:

- **心动 moment 5 种形态**(v1.0 §2.1.6):#1 字面引用 / #2 选择回响 / #3 模式识别 / #4 跨 session 记忆 / #5 现实数据穿透。其中 #1 和 #2 是 scripted 的(创作者能保证),#3-#5 是系统级(记忆/授权引擎)。**首 session 前 3 beat 必命中一次 #1 或 #2** · 这是 Tipsy 学来的密度。
- **通道开启时机**:5-10 session 完成相遇仪式后触发。太早关系没建立,太晚用户流失。别墅第七号提供了新变量 — **多结局的通道开启 UI 事件不同**(3 种字条 / 3 种关系基础)。
- **生图时机**:关键 moment 才生成 · 不能每 beat 都图。目前判断是:相遇场景 / 心动瞬间 / fade-to-black 前 · 每 session 1-2 张封顶。
- **fade-to-black 时机**:亲密度突破关键点的**下一秒** — 早了不够 · 晚了违反抖音尺度 + 我们自己的产品哲学("fade-to-black 是产品机制不是审查妥协")。
- **AI 主动来消息不扣分 + 沉默降级** — 用户每次打开 app 看到"她给你写了信"是免费的甜头,回信才扣分(留存核心)。长期不回,AI 自动衰减(用户 1 月+不回,AI 就退,保持 AI 尊严 = 反 Replika 舔狗路线)。

这套分值体系接下来需要**从每个作品的运营数据中反推调优** — 心动 moment 是否在正确时机触发,通道开启后留存 curve,生图付费转化,等等。**这是招 PM 上任后的第一批工作**。
